# Каталог цветов

Локальное приложение без базы данных. Запустите локальный веб-сервер в этой папке и откройте его адрес в браузере (например, через расширение Live Server в VS Code). Страница напрямую из файла может не загрузить `colors.json` из-за ограничений браузера.

## Данные

Редактируйте `colors.json`. Каждая запись — один цвет; у цвета свой ID для ссылки, название палитры, имя цвета и HEX-код:

```json
{
  "id": "52620FD7B427821",
  "paletteName": "Название палитры",
  "name": "Название цвета",
  "hex": "#FF00AA"
}
```

Добавляйте записи с одинаковым `paletteName`, чтобы собирать цвета в одну палитру. Кнопка «Открыть все цвета» открывает ссылку каждого цвета. Для сортировки RGB используется порядок каналов R, затем G, затем B. По клику на цвет показываются три ближайших по расстоянию RGB примера; повторный клик открывает страницу товара.
