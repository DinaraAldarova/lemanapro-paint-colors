# Каталог колеровки Лемана ПРО

На сайте Лемана ПРО неудобно просматривать большие палитры оттенков. Этот статический каталог показывает цвета крупными квадратами, помогает сравнивать оттенки и открывать выбранный цвет в карточке подходящей краски. В репозитории уже лежат каталоги A и C; данные могут со временем устареть, поэтому их можно просматривать как есть или заново выгрузить с сайта скриптом.

## Типы основы

- **A** — белая основа для пастельных цветов.
- **C** — прозрачная основа для ярких цветов.

Для каждого типа используется отдельный файл: `catalog-type-a.json` и `catalog-type-c.json`. В каталоге можно показать оба типа вместе или переключиться только на A либо C. Сейчас A содержит 14 706 цветов в 22 палитрах, C — 7 520 цветов в 21 палитре. Эти выгрузки можно обновить, когда сайт изменит каталоги.

## Запуск без сервера

### Локально

1. Откройте `index.html` двойным щелчком.
2. Нажмите **Загрузить каталог A** и выберите `catalog-type-a.json`.
3. Для каталога C нажмите **Загрузить каталог C** и выберите `catalog-type-c.json`.

Браузер не разрешает локальной HTML-странице автоматически читать соседние JSON-файлы, поэтому при запуске через `file://` их нужно выбрать вручную. Установка или запуск веб-сервера не требуются. Кнопки загрузки также подходят для выбора обновлённых файлов.

### GitHub Pages

Разместите файлы в репозитории и включите GitHub Pages для ветки/папки, где находятся `index.html` и оба JSON-каталога. На опубликованном сайте JSON загрузятся автоматически. Для обновления каталога замените соответствующий файл и отправьте изменение в GitHub.

## Ссылки на товары

Панель ссылок свёрнута, чтобы не занимать место. Откройте её кнопкой **Настроить ссылки**, укажите URL товара с нужной основой A или C и сохраните. Приложение добавит ID выбранного цвета в параметр `robotint-share`. Ссылки сохраняются в текущем браузере; на локальной странице браузер может не сохранять настройки между сеансами, поэтому их можно ввести повторно.

Не используйте ссылку на белую краску с цветом, рассчитанным для прозрачной основы, и наоборот. У каждой карточки показан тип основы, к которому относится цвет.

## Каталог данных

Каждый файл имеет одинаковую структуру и поле `baseType` (`A` или `C`):

```json
{
  "schemaVersion": 1,
  "baseType": "A",
  "generatedAt": "2026-11-19T12:00:00.000Z",
  "complete": true,
  "errors": [],
  "palettes": [
    {
      "id": "803",
      "name": "DULUX TRADE",
      "colors": [
        { "id": "626518", "name": "30YR 17/341 - 30YR17/341", "hex": "#AA5E52" }
      ]
    }
  ]
}
```

У палитры свой ID и название; у каждого оттенка — свой ID, название и HEX-код. Кнопками **Загрузить каталог A/C** можно открыть свои JSON-файлы в приложении. Загруженные файлы заменяют каталог соответствующего типа только в открытой вкладке.

## Поиск и сравнение

- Переключатель **Все типы / Основа A / Основа C** фильтрует карточки и избранное.
- Поиск работает по названию цвета, HEX и ID; можно также ограничить список палитрой.
- Сортировка: RGB, яркость, оттенок (hue), насыщенность, название палитры или цвета. Кнопка направления меняет порядок на обратный.
- Панель поиска цвета свёрнута. Откройте её кнопкой **Поиск по цветовому кругу**, введите, например, `#FF00AA` или `rgb(255, 0, 170)`, либо выберите цвет встроенным селектором браузера. Сначала приложение набирает порции цветов по близости в OKLab; внутри каждой порции действует выбранная сортировка.
- Для RGB можно выбрать первичный канал (R, G или B), направление и шаг округления. По умолчанию шаг 10: значения 145 и 146 попадают в одну группу, а 145 и 165 — в разные.
- При поиске по выбранному цвету кнопка **Показать ещё** добавляет следующую ближайшую порцию и сортирует её отдельно. Если поменять способ сортировки, перестраивается весь уже показанный список. Пока образец активен, **Сбросить** выделена и доступна; она очищает выбранный цвет. После сброса выбранная сортировка применяется ко всему отфильтрованному каталогу, а страницы показываются последовательно.
- По нажатию на квадрат показываются до 10 ближайших оттенков той же основы.
- Чтобы не создавать тысячи элементов разом, каталог показывает по 120 карточек; кнопка **Показать ещё** добавляет следующую порцию.

## Избранное

Нажмите звёздочку на карточке, чтобы добавить цвет в избранное. Браузер может хранить этот список локально, но сайт не гарантирует его сохранность. Регулярно скачивайте резервную копию JSON. Её можно загрузить кнопкой в разделе избранного, чтобы восстановить или объединить записи.

В избранном также доступны TXT со строками вида «тип основы — палитра — цвет — HEX — ID». Только в режиме избранного показывается кнопка **Открыть все результаты**; она открывает ссылки, подходящие под текущие фильтры. Браузер может ограничить большое число новых вкладок.

## Обновление каталогов с сайта

Один сценарий `devtools-refresh-catalog.js` повторяет рабочую последовательность запросов: `POST action=init` получает HTML виджета со списком палитр, затем `POST action=get-colors` получает цвета каждой палитры по `COLLECTION_ID`. Выберите основу A или C — сценарий скачает соответствующий файл. `get_styles` нужен только как источник актуального `SECRET`: его ответ содержит CSS, а не список палитр.

### Найти параметры запроса

1. Откройте на `perm.lemanapro.ru` страницу краски с нужным типом основы и дождитесь загрузки виджета колеровки.
2. Нажмите **F12** и откройте **Network**. Если список запросов пуст, обновите страницу при открытой вкладке.
3. В фильтре введите `exchange/?action`.
4. Чтобы скопировать `SECRET`, выберите запрос `action=get_styles`, откройте **Headers → General → Request URL** и скопируйте значение после `SECRET=` до следующего `&`. Сам `get_styles` возвращает CSS и не содержит списка палитр.
5. Найдите запрос `action=init` с методом **POST**. В **Payload** скопируйте `BARCODE` именно от товара с выбранной основой A или C. Тело запроса содержит `action=init`, `stylesInited=1`, `BARCODE`, `CLIENT_ID`, `SECRET`, `WITH_PRICE`, `USE_SWITCHER`, `USER_ID` и `version`.

Ответ `init` — HTML-виджет. В нём меню палитр размечено элементами `tint-select-item` с `data-value` (ID палитры); также в HTML есть цвета текущей выбранной палитры. Например, в приложенном ответе `init` обнаружены 21 пункт меню и 813 цветов выбранной палитры NCS Second Edition. Для полного каталога сценарий отдельно запрашивает `get-colors` по ID каждой палитры.

### Выгрузить палитры и цвета

1. Оставаясь на странице товара, откройте в DevTools вкладку **Console**.
2. Откройте `devtools-refresh-catalog.js` в редакторе, скопируйте весь файл, вставьте в Console и нажмите Enter. Перед запуском прочитайте локальный сценарий; если браузер предупреждает о вставке, следуйте подсказке DevTools.
3. В появившейся панели выберите основу A или C, введите `SECRET` и `BARCODE` из `action=init`, нажмите **Обновить каталог**.
4. Сценарий отправит `POST action=init` с этими параметрами, извлечёт палитры из HTML-ответа, а затем отправит `POST action=get-colors` для каждого `COLLECTION_ID`. Из ответов `get-colors` берутся ID, название и HEX каждого цвета.
5. При полном успехе скачается `catalog-type-a.json` или `catalog-type-c.json`. Если часть палитр не загрузилась, скачается файл с суффиксом `-partial`; проверьте строки `ERROR` в Console и не заменяйте им полный каталог, пока не разберётесь с ошибками.
6. Для локального просмотра выберите свежий JSON кнопкой загрузки в приложении. Для GitHub Pages замените соответствующий файл в репозитории.

`SECRET` вводится в панель браузера и не записывается в каталог или сценарий. Сценарий не отправляет cookies (`credentials: omit`). `fetch.js` и `secret.txt` не нужны и исключены из Git. Не публикуйте полный URL запроса, секрет или дампы Network.

## Пример HTML-ответа

`example-color-picker-response-FARBE-ERLEBEN.html` сохранён как образец ответа сайта. Разбор рассчитан именно на этот формат: пункты палитр используют `class="tint-select-item"` и `data-value`; элементы оттенков содержат `data-id`, `data-name`, `data-collection-name` и HEX в `style="background:#..."` либо в `data-hex`. Если сайт изменит разметку или названия полей, понадобится скорректировать разбор в `devtools-refresh-catalog.js`.
